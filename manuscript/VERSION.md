# 写作基线与版本边界

整理日期：2026-11-18。这是第二、三章的写作材料快照，不是运行或复现实验的完整软件包。

## 主写作基线

以用户保存的tractor_mu1118.slx为结构核对基线，SHA256见[model_identity.json](chapter03/source/model_identity.json)。九个MATLAB Function从该副本的既有只读导出复制（仅统一文本行尾为LF）；起步Stateflow从同一副本直接导出XML及标签。模型本体未复制，凭本包即可读懂算法，运行联合仿真另需主模型、TruckSim、环境和场景配置。

## 不同来源的边界

1. `chapter03/source/`：保存副本的内嵌实现，优先用于描述实际算法。WorkSlip函数头部永久保留声明及所有中文注释均原样保留。
2. `chapter03/parameters/`：整理当日磁盘默认参数及校验函数，不是副本保存时MATLAB工作区P的导出。报告中的默认0.30目标、2 km/h进入和1.3 km/h退出等数值应标为默认设置；主模型可能沿用工作区已有合法P。
3. `chapter03/fixed-target-smc.md`：11月17日接口说明，控制律和预算约束可用，但根级PI/SMC选择位置属于当时版本。
4. 11月18日后续同链路版本引入`WORK_CTRL_MODE=0/1/2`，BASE/PI/SMC在公共交接前选择；不能反写成1118保存副本已经有这个模块。本包未复制PI对照、选择器或仿真数据，避免与主基线混合。
5. `chapter03/history/`：AI生成的候选设计笔记，含目标极值寻优、不同滑模面和未采用接口；只作推导素材，不能当作实现说明或正式参考文献。
6. 第二章参数表来自中期报告，技术手册文本来自11月17日平台资料；若和默认参数脚本不一致，正文需标明对象、物理口径与来源，不能悄悄合并。
