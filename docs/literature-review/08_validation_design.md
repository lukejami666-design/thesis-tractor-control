# 验证设计建议

## 试验对照

1. 均分或现有基线分配；
2. 基线 + 分配后单轮限扭；
3. 所提起步防滑 + 自适应滑移；
4. 所提统一协调分配。

## 仿真工况

| 工况 | 目的 | 必测量 |
|---|---|---|
| 高负载直线起步 | 区分未起动与空转；检查扭矩渐增/回退 | 起步时间、轮周速度差、加速度差、空转持续时间、车速建立 |
| 单轮或单轴低附着起步 | 检查单轮边界和轮间重分配 | 各轮滑移、扭矩、总驱动力残差 |
| 四轮低附着起步 | 检查全轮空转与安全降级 | 地速可信度、扭矩回退、是否错误追踪速度 |
| 作业负载阶跃 | 检查自适应目标和饱和冻结 | 速度误差、滑移峰值、目标变化率、恢复时间 |
| 转向叠加低附着 | 检查防滑约束是否破坏横摆需求 | 横摆率/航向误差、总驱动残差、横摆残差、约束激活比例 |

## 实车定深作业

使用 CAN 轮速、轮端扭矩/电流、转角，GNSS 地速/位置及 IMU。每组在相同农具、作业深度、速度指令和尽量相近土壤条件下重复；策略顺序随机化。记录土壤含水率、锥入度、通过次数和路线。若无独立牵引力传感器，不把估计牵引效率作为主结论。

主指标：GNSS 地速建立时间与速度误差、滑移率均值/RMS/峰值、超过阈值时长、有效作业距离或合格作业时间占比、扭矩变化率、航向/横摆误差、约束激活与需求残差。增强指标：固定采样点的车辙深度作为土壤扰动代理。
