# 可直接用于绪论的综述写作结构

## 0.2.1 大型电动农机与分布式驱动

先说明独立轮端扭矩提供的控制自由度，再指出低速高负载、非均匀地面、作业阻力波动与道路车辆不同。`B03` 可用于牵引试验测量链与电动 AWD 平台实例；不要用其证明控制策略优越。

## 0.2.2 低速状态获取与起步防滑

按“滑移反馈依赖地速—低速失效—替代运动量—起步与正常阶段交接”写。`B02` 是关键反证：其自适应滑移控制仍以可靠车速为前提。网络恢复后必须补充角加速度、轮周速度差、模型跟随、最大可传递扭矩等原始文献。

## 0.2.3 农机牵引与自适应滑移

比较固定设定值、土壤模型计算和在线更新。`B01` 支持模型/参数驱动的设定值更新，`B02` 支持观测器和轮胎模型驱动的在线最优目标。明确它们解决的是正常运动中的最优滑移，而非四轮全滑时的地速可观测性。

## 0.2.4 航向保持与横摆控制

将已有 IJAT 直线航向成果单列为研究基础；新增部分仅讨论中低速转向的横摆需求接口。`B04` 支持层级 DYC 和附着相关下层分配，但应说明对象是道路车辆。

## 0.2.5 多目标协调与四轮扭矩分配

从“分配后限扭会改变上层总驱动/横摆目标”切入，比较加权 QP、严格分级、MPC、CBF-QP和学习型分配。`B04`、`B05`、`B06`、`B07` 用于说明多目标分配的不同结构，不能替代农机低速实车证据。
